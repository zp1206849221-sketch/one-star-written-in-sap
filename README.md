# One Star, Written in Sap

A single one-line 1-star review written by a houseplant about its human
owner: two years root-bound in its nursery pot, rotated so its
light-starved side faces the wall whenever guests come over to hear its
owner call herself a plant mom.

## How to run

```sh
python3 main.py
```

This writes the one-line review to `/output/entry.txt` (creating the
directory if needed). Python standard library only.
